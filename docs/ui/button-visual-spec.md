# Button 视觉规范

更新：2026-09-29。根据用户确认的整体按钮方案实施。

## 层级

| 角色 | variant | 默认表现 |
| --- | --- | --- |
| 主操作 | default | 深色实心、白字 |
| 次操作 | secondary | 白底、中性灰细边框、深色文字 |
| 辅助操作 | ghost | 透明底，悬停与按下提供灰底反馈 |
| 危险操作 | destructive | 红色实心、白字 |

`outline` 保留为 `secondary` 的视觉兼容别名，不再构成独立层级。业务页面沿用现有调用，无需逐页补背景或边框。

## 状态

- 次按钮悬停时背景变浅灰、边框加深；按下时背景进一步加深。
- 主按钮与危险按钮提供独立的悬停、按下色；取消整体缩放，保持布局稳定。
- 键盘焦点使用清晰的外侧轮廓和留白，避免只靠很淡的阴影。
- 禁用时使用灰底、灰字及完整边框，不再把整个按钮降为半透明；不响应悬停和按下色。
- 加载时保留原有颜色层级，沿用禁用与 aria-busy 语义及已有加载反馈。
- 状态选择器依据最终 DOM 的 disabled / aria-busy，兼容 Radix asChild 组合。
- 颜色集中在 theme.css 的 Button token 中；视觉实现仅使用 Button 内的 Tailwind 工具类。

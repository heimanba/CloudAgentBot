# 助手管理页与共享入口优化验收

日期：2026-09-29。

## 设计依据与落地

研究依据见 [官方产品共享模式研究](../research/bot-sharing-ui-patterns.md)。采用「入口常驻、解释按需、取消进入设置」原则，不迁移外部产品权限模型。

- 删除页头说明段落与共享长文，移除每行 Managed、空描述兜底、远程 ID 及重复共享标签。
- 页头只保留标题和创建操作。工具栏用 Tabs 表示我的助手、团队共享、全部；全部保留恢复资料与工作区资源发现入口。协调者由独立角色筛选叠加，不再与范围平级。
- 名称、有效描述与右侧操作位于同一行；复制 ID、同步和归档位于更多菜单。协作关系在有实际成员引用时保留。
- 列表与详情共用 BotShareAction。共享或已共享均打开 Popover；面板内显示同 Provider / API Key 的发现范围、跨设备历史事实与权限边界，再明确开启或取消。
- 失败可重试，提交中禁用，成功状态依赖 Provider 列表刷新；不乐观猜测共享成功。

## 实际 Electron 检查

使用现有百炼连接，在正在运行的 Electron 开发应用中操作。此轮只检查 UI，没有修改已有助手的共享状态或创建远程资源。

1. 管理页首屏不出现 API Key 长文、ID 或重复共享标签；共享入口直接可见。
2. 点击已共享只打开设置，取消操作位于面板内；Escape 关闭并把焦点还给共享按钮。
3. 协调者筛选产生正确空态；清除筛选恢复当前范围的列表。
4. 我的助手 / 团队共享切换可用。
5. 打开助手详情，使用同一共享面板与说明；返回列表正常。
6. macOS 左半屏约 757 逻辑像素下检查页头、Tabs、搜索和助手操作，无横向裁切。
7. 输入不存在的名称出现当前范围无结果；清除搜索保留范围并恢复列表。
8. 结束时恢复原窗口大小，留在管理页。

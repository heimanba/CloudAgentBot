# UI 审查修复验收

日期：2026-10-04。

## 范围与问题确认

本次依据当前源码和隔离模拟数据渲染结果，修复五项 UI 问题：占位文字对比度、重复主创建入口、窄窗口聊天页头拥挤、圆角定义分叉、窄窗口发送按钮尺寸。开发计划和临时截图位于忽略目录 `.scratch/ui-audit-20261004/`，不是现行规范的依赖。

未访问真实 Cloud，未读取或修改凭据。浏览器模拟 DesktopHost 只用于 Renderer 视觉检查，不代表 Provider 验收。

## 修复与实测

| 项目 | 修复前 | 修复后与验证 |
| --- | --- | --- |
| Input、Textarea 占位文字 | `#666666` 再应用 80% 透明度，白底约 3.71:1 | 移除透明度；创建表单及工作记录搜索计算样式均为 `rgb(102, 102, 102)`，白底约 5.74:1 |
| 助手空列表 | 页头和空状态均有黑底创建按钮 | 1280px、375px 下只有一个「新建助手」主按钮；点击可进入创建表单；有数据、加载或错误时保留页头入口 |
| 聊天页头 | 375px 下工具区把助手身份挤成省略文字 | 窄窗口身份与工具分两行，示例「由项目分析助手处理」完整显示；工作记录筛选与跳转弹层均可打开；1280px 保持单行布局 |
| 圆角来源 | `rounded-md` 为 8px，直接变量为 9px；lg、xl 同样分叉 | 统一为独立非 inline 的 static theme，沿用冻结的 6/9/12/16px；实测 md 工具类与变量均为 9px |
| 聊天发送区域 | 375px 下发送、附件按钮为 36×36px | 窄窗口复用 `--control-lg`，实测均为 44×44px，页面无水平溢出；桌面保持 36px |

窄窗口页头增加一行高度，以换取可辨识的身份和工具直接入口。本次没有改变菜单、Popover、发送或 Provider 行为。未覆盖所有协作人数、超长名称和所有弹层组合。

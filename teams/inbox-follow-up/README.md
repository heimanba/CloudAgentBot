# 收件箱跟进

一个双 Bot 销售运营工作台，找出确实轮到你们回复的对话，并准备有据可依的草稿。

## 成员

- **Keeper — 销售运营分析师：** 负责会话状态、排除项、归属与优先级。
- **Nudge — 跟进文案撰写：** 负责基于真实往来、简洁克制的草稿。

## 内置 Skill

- **跟进分类（Follow-up Triage）：** 生成干净的待跟进队列，排除已退订、已关闭与重复项。
- **精准跟进（Specific Follow-up）：** 起草最小可用的下一步，不编造上下文。

Gmail 为必需，HubSpot 可选。连接均在 OpenMausBot 内完成；消息绝不会自动发送。

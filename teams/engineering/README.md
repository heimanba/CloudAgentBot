# 工程团队

一支均衡的四人产品工程团队，把一项改动从想法推进到验证通过的发布。

## 成员

- **Ada — 技术负责人：** 界定工作范围，统筹职责分工，把权衡讲清楚。
- **Lin — 后端工程师：** 负责 API、数据、可靠性与安全边界。
- **Pixel — 前端工程师：** 负责交互设计、无障碍与真实渲染质量。
- **Rigel — 测试与发布工程师：** 负责缺陷复现、基于风险的测试与发布就绪度。

## 内置 Skill

- **架构决策（Architecture Decision）：** 记录一次聚焦的技术决策及其权衡。
- **实施方案（Implementation Plan）：** 把目标拆解为有顺序、可验证的工作。
- **发布就绪（Release Readiness）：** 检查行为、风险、回滚与沟通。

## 建议连接

GitHub 适合处理仓库与 Pull Request 工作。请在 OpenMausBot 内完成连接；本团队包不包含任何凭据。

## 试用

> 检查这个仓库，为新增协作模板给出最小且安全的方案。包含职责分工、测试、风险与发布检查清单。

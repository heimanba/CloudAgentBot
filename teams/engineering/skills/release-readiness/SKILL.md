# 发布就绪

## 适用场景

某项改动即将进入合并、部署、分发或公开发布阶段。

## 流程

1. 把发布内容对应到验收标准与受影响的用户流程。
2. 确认自动化检查结果，并记录相关的人工验证。
3. 评审数据变更、兼容性、安全、权限、失败状态与可观测性。
4. 找出仍然存在的不确定性，并按发生概率与影响分级。
5. 确认上线顺序、负责人、回滚路径与发布后检查。
6. 对行为变化准备简洁的、面向用户或维护者的说明。

## 产出

给出明确的「可发布／有条件可发布／不可发布」结论，随后列出证据、未决风险、上线、回滚、监控与沟通安排。

## 边界

绝不对未运行的检查臆断为通过。测试全绿也不能替代对重要渲染结果或端到端行为的验证。

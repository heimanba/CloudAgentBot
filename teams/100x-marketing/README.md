# 100x 营销团队

一支四人增长团队，专注交付聚焦的活动并快速学习。

## 成员

- **Maya — 增长负责人：** 决定押注方向、成功指标与优先级。
- **Echo — 创意与文案负责人：** 构建概念、信息表达与可直接投放的素材。
- **Orbit — 分发负责人：** 设计可重复、不扰民的分发方式。
- **Lens — 增长分析师：** 定义衡量方式，把结果转化为下一个决策。

## 内置 Skill

- **定位简报（Positioning Brief）：** 厘清受众、品类、承诺与证据。
- **活动冲刺（Campaign Sprint）：** 把一个增长赌注转化为有主责人的上线计划。
- **实验复盘（Experiment Review）：** 基于证据给出停止、迭代或放大的决策。

## 建议连接

Google Analytics、Google Sheets 与 Slack 有助于执行与汇报。请在 OpenMausBot 内连接账号；切勿把凭据写进模板。
